# 🕷️ Tejeswararao — Personal Portfolio

### Spider-Themed Developer Portfolio

A modern, responsive personal portfolio website designed to showcase my professional profile, technical skills, projects, education, and experience. The website features a spider-inspired design with a black-and-red color scheme, bold typography, and a comic-style interface.

## 🚀 About the Project

This portfolio serves as my digital professional identity, presenting my background as a Software Developer and AI & ML Enthusiast. It provides visitors with easy access to my projects, resume, technical skills, and professional profiles.

The project also demonstrates the use of **Prompt Engineering** to translate design ideas and requirements into a customized web interface.

## ✨ Features

- 🕷️ Spider-inspired visual theme
- 🏠 Home page with developer introduction
- 👤 About section
- 💻 Technical skills showcase
- 💼 Experience and internship details
- 📂 Projects showcase
- 🎓 Education details
- 📄 Resume download option
- 🔗 GitHub and LinkedIn links
- 📬 Contact section
- 📱 Responsive user interface

## 🎨 Design and Ideology

**Design:** The website uses a dark background, red accents, white typography, glowing borders, bold headings, and spider-themed artwork to create a distinctive comic-inspired interface.

**Ideology:** The main idea is to establish a unique professional digital identity, present technical capabilities in one place, and make it easy for recruiters and visitors to explore my work.

## 🛠️ Technologies Used

- **Frontend:** React.js
- **Build Tool:** Vite
- **Styling:** CSS and Tailwind CSS
- **Programming Language:** JavaScript
- **Icons:** Lucide React
- **Version Control:** Git and GitHub

## ⚙️ Installation and Setup

### Prerequisites

- Node.js and npm installed
- Visual Studio Code
- Git (optional, for version control)

### Steps to Run Locally

**1. Clone the repository**

```bash
git clone https://github.com/Tejeswararao1646/Myportfolio.git
```

**2. Open the project folder**

```bash
cd Myportfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the website**

Open the local URL displayed in the terminal. For example:

```text
http://localhost:3000/
```

The port may differ depending on your Vite configuration.
